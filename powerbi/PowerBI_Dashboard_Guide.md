## 🛠️ Build

1. Open **Power BI Desktop → Get Data → Text/CSV**.
2. Select `dataset/retail_sales.csv`.
3. Use **Power Query** to verify data types and transform the data.
4. Create the **DateTable** and required **DAX measures**.
5. Build the two dashboard pages above.
6. Apply consistent formatting, labels, and navigation.
7. Save as `Retail_Sales_Dashboard.pbix`.

> **Note:** The `.pbix` file must be created and saved from Power BI Desktop.
